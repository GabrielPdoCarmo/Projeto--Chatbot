# Chatbot — Experimento de Programação e Inteligência Artificial

Protótipo de uma interface de chatbot desenvolvida para um projeto de pesquisa de Mestrado em Engenharia de Software.

O projeto tem como objetivo fornecer um ambiente para investigar a interação de estudantes com agentes de Inteligência Artificial durante a resolução de problemas de programação.

## Sobre o projeto

A pesquisa busca investigar como estudantes interagem com agentes de IA durante atividades de programação, com foco na **calibração de confiança**.

O estudo considera aspectos relacionados à interação entre humanos e agentes de Inteligência Artificial, buscando compreender como os estudantes:

- utilizam a IA durante a resolução de problemas;
- interpretam as respostas fornecidas pelo agente;
- avaliam a confiabilidade das respostas;
- identificam possíveis erros nas respostas da IA;
- utilizam o agente como apoio durante a resolução.

O cenário previsto para o estudo é a disciplina de **Fundamentos de Programação**.

## Objetivo do protótipo

Este projeto representa uma primeira versão da interface que será utilizada no experimento.

O protótipo atualmente contempla:

- Tela inicial do experimento;
- Tela de instruções;
- Interface de chatbot;
- Envio de mensagens;
- Histórico da conversa;
- Respostas simuladas do assistente.

A definição dos problemas utilizados no experimento, das respostas controladas e dos erros apresentados pela IA ainda será realizada de acordo com o protocolo de pesquisa.
